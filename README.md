# Telegram bot MVP

Минимальный бот, который принимает текстовые запросы и подтверждает, что запрос принят.
Сервер пока не подключен (заглушка).

## 1) Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 2) Настройка токена

1. Скопируйте `.env.example` в `.env`
2. Вставьте токен от BotFather в `TELEGRAM_BOT_TOKEN`

## 3) Запуск

```bash
python bot.py
```

## Что умеет сейчас

- `/start` показывает приветствие и пример запроса
- Любой текстовый запрос логируется в консоль
- Пользователь получает ответ: запрос принят (заглушка до подключения backend)
