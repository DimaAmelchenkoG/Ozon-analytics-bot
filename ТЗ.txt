1. Цель проекта

Разработать систему, которая позволяет пользователю (клиенту) отправлять запросы в 
Telegram-бот и получать аналитические ответы по продажам.

Примеры запросов:

«Сколько товаров я продал сегодня?»
«На какую сумму были продажи за вчера?»
«Какие товары продаются лучше всего?»

Ответ формируется с использованием:

данных из таблиц (Google Sheets / БД)
данных из Ozon (через API)
обработки запроса через нейросеть 

2.Общая архитектура
Компоненты системы:
Telegram-бот
Backend (сервер)
Модуль интеграции с Ozon API
Модуль работы с таблицами (Google Sheets / БД)
Модуль обработки запросов (AI)
База данных (при необходимости кеширования)

3. Telegram-бот
Функции:
Прием текстовых запросов от пользователя
Отправка запроса на backend
Получение и отображение ответа
Требования:
Поддержка русского языка
Логирование запросов

4. Backend (сервер)
Основные задачи:
Принимать запрос от бота
Обрабатывать его
Обращаться к источникам данных
Формировать ответ

5. Модуль AI 
Задачи:
Понимание запроса на естественном языке
Преобразование запроса в структурированный формат
Генерация ответа

6. Интеграция с источниками данных

6.1 Ozon API
Получение данных 
6.2 Таблицы (Google Sheets / БД)

7. Логика обработки запроса

Пользователь отправляет запрос
Бот передает его на сервер
AI обрабатывает запрос
Backend:
запрашивает данные из Ozon + таблиц
агрегирует данные
Формируется ответ
Ответ отправляется пользователю
